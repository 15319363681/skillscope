# SkillScope 实施计划

日期 2026-11-21

## 产品范围

面向 AI Agent SKILL.md 的本地可运行网站。React 与 TypeScript 实现界面，Express 提供评分与导入 API，JSON 原子写入保存评测。公开仓库导入仅支持 GitHub。

## 视觉与交互

黑曜石工作台、荧光绿强调、克制的网格与宽松留白。评分雷达作为视觉中心。页面进入、雷达扫描和报告展开采用轻量动画，遵循减少动态效果的系统设置。

## 实施顺序

1. 编写评分与导入边界测试，运行并确认缺少实现时失败。
2. 实现 YAML 解析与六维规则，返回逐项命中、证据行号、建议和权重。
3. 实现持久化 API、GitHub 文件导入和原创示例库，验证重复提交与并发写入。
4. 实现发现、榜单、收藏、比较、评测弹窗、报告与评分方法页面。
5. 运行类型检查、生产构建、API 测试和 Chrome 浏览器交互检查，检查桌面和移动端。

## 评分定义

指令清晰度 20%，执行完备度 20%，安全边界 20%，上下文效率 15%，可迁移性 15%，维护规范 10%。每项细分规则采用确定性文档检查。结果反映主文件的静态质量，真实任务成功率需要独立运行实验。所有内置条目注明原创示例。

## 交付

完整源代码、可访问的本地服务、中文运行说明与通过的验证结果。
