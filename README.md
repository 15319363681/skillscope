# SkillScope

SkillScope 是一个针对 AI Agent `SKILL.md` 的本地评测网站。它从六个维度给出可追溯的静态评分，支持提交、发现、比较和收藏 Skill。

## 快速开始

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 22 及以上。

```powershell
cd D:\skillscope
npm install
npm run build
npm start
```

打开 http://127.0.0.1:4173。开发时可以运行 `npm run dev`。服务默认只监听本机，设置环境变量 `PORT` 可以更改端口。

## 使用方式

1. 在发现页浏览示例，或点击「评测 Skill」。
2. 粘贴内容、上传 Markdown 文件，或输入公开 GitHub 仓库、文件、目录链接。
3. 选择分类并开始评测，报告展示综合评分、六维雷达图、逐条检查、证据与改进建议。
4. 收藏 Skill 或加入对比，最多同时比较三个。榜单按综合评分排序。

仓库地址默认读取其默认分支根目录的 `SKILL.md`。公开 GitHub 目录地址会读取目录下的 `SKILL.md`。导入需要可访问 GitHub，分支名含斜杠时建议直接上传或粘贴文件。GitHub 接口可能有限流。

## 评分与范围

| 维度 | 权重 |
| --- | ---: |
| 指令清晰度 | 20% |
| 执行完备度 | 20% |
| 安全边界 | 20% |
| 上下文效率 | 15% |
| 可迁移性 | 15% |
| 维护规范 | 10% |

综合分为六维得分的加权和。规则主要依据 YAML 结构和文本特征，报告显示每条检查、适用的原文行号和建议。检测到高风险命令或指令覆盖文本时，安全维度上限为 35 分。名称与 frontmatter 的检查参考 [Agent Skills specification](https://agentskills.io/specification)，权重与质量规则由 SkillScope 定义。

报告仅覆盖提交的主文件，不读取引用的文件，也不执行 Skill。规则命中不代表语义正确、实际任务成功或安全性得到保证。建议结合人工审查与真实任务验证。内置数据为原创示例，明确标注，并非真实社区排名。

## 数据与部署范围

评测内容和报告保存在项目下 `data/skills.json`，以明文形式存储，重新启动后保留。收藏和对比列表存储在浏览器 localStorage。相同内容的重复提交会复用已有报告。

此版本面向单机本地使用，没有账号、多用户权限或公网部署配置。请勿将本地服务直接暴露到公网。GitHub 导入仅访问公开文件，不需要令牌。

## 验证

```powershell
npm test
npm run build
npm run test:ui
```

浏览器测试默认使用 Windows 的 Chrome 路径，也可以设置 `CHROME_PATH`。浏览器测试使用临时数据目录。

## 社区数据与 LLM 语义分析

社区榜单读取 skills.sh 网站公开展示的 all-time 榜单，按其累计安装数原顺序展示，保留获取时间与来源。服务启动后立即更新一次，之后每小时由服务端刷新；页面只读取当前缓存，不会轮询上游。安装量代表社区热度，不是质量、安全或成功率。上游不可用时会显示最近缓存或明确提示失败。当前仅接入 skills.sh 一个来源，无法代表整个 Skill 社区。

静态规则分数用于查看文档特征，六个维度与权重尚未经过标注数据校准。可在报告中选择运行独立的 LLM 语义分析，它输出维度判断、行号、建议与模型信息，不会自动执行 Skill。模型结果依旧需要人工核对和真实任务验证。

在左侧打开「LLM 服务」，填写 OpenAI 兼容的 Chat Completions 服务地址（包含 `/v1`）、模型名和 API 密钥，可先保存再测试连接。配置只保存在当前服务进程内存中，不写入报告文件，也不会回传到浏览器；服务重启后需重新配置。模型需支持 `response_format: {type: "json_object"}`。用户在报告页面点击分析后，SKILL.md 内容会发送给所配置的模型服务，结果保存在本地数据文件。请根据内容敏感性选择可信的服务。
