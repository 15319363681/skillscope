# SkillScope

SkillScope 帮你检查 AI Agent 使用的 `SKILL.md`。它会把文档拆成六个方面评分，并指出检查依据和可以改进的地方。你也可以浏览社区热门 Skill、比较不同 Skill，或让自己信任的模型服务做进一步分析。

## 先运行起来

需要 Node.js 20.19 以上，或 22.12 以上版本（建议使用 Node.js 22）。打开 PowerShell，运行：

```powershell
cd D:\skillscope
npm install
npm run build
npm start
```

启动后，在浏览器打开 <http://127.0.0.1:4173>。要停止服务，在 PowerShell 窗口按 `Ctrl+C`。

日常开发可以运行 `npm run dev`，代码修改后页面会自动更新。

## 怎么使用

打开「发现 Skills」可以浏览内置示例和你自己评测过的 Skill。点击「评测 Skill」，可以选择以下任一种方式提交：

- 粘贴 `SKILL.md` 内容。
- 上传 Markdown 文件。
- 导入公开的 GitHub 仓库、文件或目录链接。

提交后会生成一份报告，包含总分、六维评分图、逐项检查结果、原文证据和改进建议。报告里的收藏按钮可以把 Skill 加入收藏；在列表中选择「对比」，可以把最多三个 Skill 放在一起查看。

GitHub 导入只读取公开内容，不需要填写 GitHub 密钥。仓库链接默认读取根目录的 `SKILL.md`；目录链接读取该目录中的 `SKILL.md`。如果 GitHub 暂时无法访问或请求次数受限，可以改为上传文件或粘贴内容。

## 分数怎么看

静态评分会检查文档里能明确识别的内容，例如目标、步骤、安全说明和维护信息。六个维度的权重如下：

| 维度 | 权重 | 主要检查内容 |
| --- | ---: | --- |
| 指令清晰度 | 20% | Skill 的用途、触发场景和输出要求是否清楚 |
| 执行完备度 | 20% | 是否说明步骤、验证方式和异常处理 |
| 安全边界 | 20% | 是否说明权限范围、敏感信息和高风险操作 |
| 上下文效率 | 15% | 内容是否简洁，是否避免重复或不必要的信息 |
| 可迁移性 | 15% | 是否交代依赖、运行环境和平台差异 |
| 维护规范 | 10% | 名称、描述和维护信息是否完整 |

总分是六个维度分数按权重计算后的结果。报告会尽量指出对应的原文行号，帮助你判断建议是否合理。

需要知道的是：静态评分检查的是文档，不会执行 Skill，也不会读取它引用的其他文件。因此，分数不能证明 Skill 一定能完成任务或完全安全。内置条目是用于演示的原创示例，不代表真实社区排名。名称和文档格式的部分检查参考了 [Agent Skills 规范](https://agentskills.io/specification)；评分规则和权重由 SkillScope 自行制定。

## 配置 LLM 服务

如果希望报告提供更深入的语义分析，先在左侧打开「LLM 服务」，填写兼容 OpenAI Chat Completions 接口的服务地址、模型名称和 API 密钥，然后保存并测试连接。服务地址通常以 `/v1` 结尾，例如 `https://模型服务地址/v1`。本机运行的服务也可以使用 HTTP 地址。模型服务需要支持 JSON 输出模式。

配置成功后，打开某份报告并点击「开始分析」。分析时，这份 `SKILL.md` 的主文件内容会发送到你配置的模型服务。模型判断可能有误，引用和建议仍需要你检查；这项分析也不会运行 Skill。

API 密钥只保存在当前 SkillScope 服务进程的内存里，不会写入评测数据，也不会显示回页面。重启 SkillScope 后，需要重新填写密钥。

## 社区榜单

「社区榜单」展示 skills.sh 公开页面提供的 Skill 和累计安装量。服务启动时会获取一次榜单，之后每小时自动更新；打开榜单页面只读取当前缓存。上游暂时不可用时，页面会尽量显示上次成功获取的数据。

榜单的安装量只表示使用热度，不是 Skill 质量、安全性或任务成功率。SkillScope 目前只读取 skills.sh 的公开榜单，不能代表整个 Skill 社区。

## 数据保存与隐私

- 你提交的 Skill 内容和评测报告保存在本机的 `data/skills.json`，服务重启后仍会保留。
- 相同内容再次提交时，会复用已有的评测报告。
- 收藏和对比清单保存在当前浏览器中。
- 如果使用 LLM 分析，主文件内容会发送给你配置的模型服务；请先确认该服务适合处理这些内容。
- GitHub 导入只支持公开文件。请不要提交你无权分享的内容、密码或 API 密钥。

SkillScope 当前面向个人在本机使用，没有账号或多人权限管理。服务默认只接受本机连接，请不要直接把它暴露到公网。

## 测试项目

```powershell
npm test
npm run build
```

在 Windows 上也可以运行界面自动检查：

```powershell
npm run test:ui
```

界面检查需要安装 Chrome。如果 Chrome 不在默认位置，可以先设置路径，再运行测试：

```powershell
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:ui
```
